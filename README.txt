R Codes for 16S rRNA Microbiome Analysis of Diabetic Foot Ulcers
 Overview

This repository contains R codes associated with the analysis and visualization of 16S rRNA V3–V4 sequencing data from five diabetic foot ulcer tissue samples.

The codes are organized into separate files corresponding to the taxonomic composition and visualization workflows presented in the associated manuscript.

 R Code Files

- 01_Figure_05_Phylum_Family.txt – Phylum- and family-level bacterial composition
- 02_Figure_06_Genus_Composition.txt – Genus-level bacterial composition
- 03_Figure_08_Dominant_Taxa.txt– Dominant bacterial taxa visualization
- 04_Taxonomic_Tree_Initial.txt – Taxonomic tree construction
- 05_Taxonomic_Tree_Development_Part_1.txt – Taxonomic tree visualization
- 06_Taxonomic_Tree_Development_Part_2.txt – Taxonomic tree visualization
- 07_Circular_Tree_Heatmap_Workflow.txt – Circular taxonomic tree and abundance visualization
- 08_Circular_Tree_Later_Workflow.txt – Circular taxonomic tree visualization
- 09_Circular_Tree_Final_Revisions.txt – Circular taxonomic tree visualization

 Software

R statistical software was used for microbial community analysis and visualization, with packages including `ggplot2`, `dplyr`, `tidyr`, `readxl`, `stringr`, `patchwork`, and phylogenetic visualization packages.

 Manuscript

The repository accompanies the microbial community characterization and taxonomic visualization components of a study investigating severe diabetic foot ulcers requiring amputation.

Code Availability

The R code files are provided to document the analytical and visualization workflows associated with the manuscript.
